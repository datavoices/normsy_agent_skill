# Normsy Civic Agent privacy policy

Last updated: October 8, 2026.

## Scope

This policy describes the bundled Normsy Civic Agent plugin. It does not describe other Normsy applications or services, or the policies of the application hosting the plugin.

## Information used

The plugin contains static instructions and a bundled Markdown knowledge base. The host assistant uses the messages and context you provide to draft or revise a response. That context may include personal information if you choose to include it. The plugin does not connect to external accounts, retrieve customer records, request credentials, or provide a separate personal-data collection mechanism.

## External services and storage

The plugin has no MCP servers, hooks, executable scripts, backend calls, analytics, or external service requests. It does not send your conversations to Normsy or another service, and it has no storage of its own. Normsy receives no conversation data through this plugin and therefore retains none through it.

## Host application

Your messages, drafts, and plugin usage are processed by the application where you install the plugin. That application's privacy policy, account settings, and retention rules apply. Installing this plugin does not change those rules.

## Changes

If a future version adds external connections, data collection, or storage, this policy and the plugin documentation must be updated to describe that behavior before release.
